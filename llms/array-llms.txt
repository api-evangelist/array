# Array

> Array is an embedded fintech products platform that lets financial institutions, fintechs, credit-service companies, and consumer brands integrate consumer credit, identity, and background data into their own user experiences and marketing funnels via embeddable white-label components, private-label experiences, and APIs.

This llms.txt was generated by the API Evangelist enrichment pipeline from Array's public website. Array's developer documentation (docs.array.com) is password-gated, so no public OpenAPI specification, SDK, or reference surface is included.

- [Identity Protect](https://array.com/products/identity-protect): Identity protection and monitoring
